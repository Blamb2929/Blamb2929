# Blamb2929
A Github Portfolio highlighting some of my previous work, all repos contain a pdf file with a report style document and the code used for the project.

### [Master Thesis: Optimising Card Delivery](https://github.com/Blamb2929/Albert_Lamb_Delivery_Optimisation_Thesis)
Master's thesis optimising delivery routing using a GAM choice model to optimally offer delivery slots.

### [Statistical Modelling of Galaxy Morphology](https://github.com/Blamb2929/SIM_FinalProject)
Using the data provided by galaxy zoo, we used various machine learning methods to classify images of galaxies.

### [THE COST OF REMOTENESS](https://github.com/Blamb2929/GeoSpatialAustraliaRoads)
A Geospatial analysis of emergency healthcare access for Australians in remote areas.

### [Text Sentiment analysis of British Royal Family and UK government speeches](https://github.com/Blamb2929/Text_Mining_Final_AAF)
The aim of this project was to analyse the correlation between the themes discussed in royal speeches and the Houses of Parliament using NLP methods.

### [Reinforcement learning Zombie Game](https://github.com/Blamb2929/zombies_rl_project)
This project implements reinforcement learning (PPO) in order to play the game KnightsArchersZombies game provided by PettingZoo.
